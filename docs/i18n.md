# Internationalisation (i18n)

`src/lib/i18n.ts` adapts next-intl's `createTranslator` to the existing typed
`useTranslations(namespace)` API. Translators are memoized by language and namespace.
Messages live in `src/locales/` and use ICU `{placeholder}` interpolation.

```tsx
const t = useTranslations("stream_detail");
t("title", { id: "42" });
```

Use snake_case message keys within feature namespaces such as `home`, `dashboard`,
`stream_new`, `stream_detail`, `wallet`, `settings`, `nav`, and `common`.

## Locales

Settings offers English (`en`), Portuguese (`pt`), Spanish (`es`), Arabic (`ar`),
and Hebrew (`he`). SettingsContext persists the selected language in localStorage
and updates the root `lang` and `dir` immediately, without a reload.

English is the default. Portuguese and Spanish have complete catalogs checked by
`npm run lint`. Arabic and Hebrew currently translate navigation and language
settings; untranslated messages fall back to English. These partial catalogs are
merged with English before being passed to next-intl.

## Adding translations

1. Add or update `src/locales/<locale>.json`, preserving the namespace structure
   and ICU placeholders in English.
2. Register new locales in `src/lib/i18n.ts` and the language selector in
   `src/app/settings/page.tsx`. For partial catalogs, merge each translated
   namespace with English, as the Arabic/Hebrew entries do.
3. For another RTL language, update the RTL locale list in SettingsContext.
4. Run lint and the i18n tests. Complete catalogs should also be added to
   `scripts/check-i18n.mjs`.

## RTL layouts

Layout spacing and alignment use Tailwind logical start/end utilities. Prefer
`ms`/`me`, `ps`/`pe`, `start`/`end`, and `text-start`/`text-end` over physical
left/right utilities. Keep physical coordinates for intentionally centered items
or charts. Check new UI in both directions, including dropdowns and tooltips.
Numeric inputs and monospaced identifiers remain LTR and bidi-isolated so wallet
addresses, transaction hashes, and amounts retain their reading order.
